# Anime character base

Asset: `shino-base.glb`
Original: Sendagaya Shino, a VRoid Studio sample model by pixiv Inc.
Licence: CC0 1.0 Universal — https://creativecommons.org/publicdomain/zero/1.0/
Official model and licence statement:
https://vroid.pixiv.help/hc/en-us/articles/360013482714-Sendagaya-Shino
Source VRM mirror:
https://github.com/madjin/vrm-samples/blob/master/vroid/beta/Sendagaya_Shino.vrm

The original VRM metadata also identifies this model as Sendagaya Shino and specifies `licenseName: CC0`.

Modifications for this project: converted to standard skinned glTF; omitted unused expression morph targets and VRM metadata; reduced textures to at most 512px; neutralised hair, iris and clothing textures for tinting; merged compatible mesh primitives. The source's fully clothed body is retained. Original fantasy accessories and Three.js rendering code are separate project work. No Mushoku Tensei or Cabal character assets are included.
